# Data Structures and Algorithms

This repository contains lab assignments and practice programs for the Data Structures and Algorithms course (Semester 3).

## Contents

The repository is organized by weeks, covering various concepts and algorithms:

- **Week 1:** Introduction, Recursion (Factorial, Fibonacci, Binary Search), Compound Interest, Rocket countdown.
- **Week 2:** Searching Algorithms (Linear Search, Binary Search).
- **Week 3:** Sorting Algorithms Part 1 (Bubble Sort, Insertion Sort, Selection Sort).
- **Week 4:** Sorting Algorithms Part 2 (Merge Sort, Quicksort).
- **Week 5:** Linked Lists (Single Linked List, Circular Linked List).
- **Week 6:** Stacks (Array and Linked List implementations).
- **Week 7:** Queues (Array, Linked List, and Circular Queue implementations).
- **Week 8:** Binary Search Trees (Array, Linked List).
- **Week 9:** Binary Search Tree Operations and Traversals (Insertion, Search, Deletion, Min/Max, Node/Leaf counts, Height, Level Order).
- **Week 10:** AVL Trees (Self-Balancing BST with Rotations LL/RR/LR/RL, Insertion, Deletion, Search, Traversals, Display).
- **Week 11:** Hashing and Collision Resolution Techniques (Separate Chaining, Linear Probing, Quadratic Probing).
